# inventory-web

The React + TypeScript frontend for the inventory management app (Vite, React Router). See [SETUP.md](../../SETUP.md) for how to run it with the API and database, and [docs/architecture.md](../../docs/architecture.md) for how it fits in.

```bash
npm install
npm run dev     # http://localhost:5173, forwards /api to http://localhost:5127
npm run build
npm run lint
```
